### 2026-01-24 - S7 Protocol Implementation (Iteration 6)

#### Completed User Stories:
- **US-013**: Implemented S7 protocol connection and polling

#### Features Implemented:
- `internal/s7/client.go` - Pure Go S7 protocol implementation (no external dependencies)
- `NewClient(cfg Config)` - Creates S7 client with IP, rack, slot, port configuration
- `NewClientFromConfig(map[string]interface{})` - Creates client from connection_config JSONB
- `Connect()` - Establishes TCP connection with COTP/S7 handshake sequence
- `ConnectWithRetry()` - Connection with configurable retry count and interval
- `Disconnect()` - Clean connection teardown
- `IsConnected()` - Thread-safe connection status check
- `ReadTag(address, dataType)` - Reads values from PLC memory areas
- `ReadMultipleTags(addresses, dataTypes)` - Batch read helper

#### S7 Protocol Features:
- TPKT/COTP connection establishment
- S7 Communication Setup with PDU size negotiation
- S7 Read Variable request/response handling
- Proper sequencing with PDU reference numbers

#### Address Format Support:
- Data Blocks: `DB1.DBW0`, `DB1.DBD4`, `DB1.DBX0.0`
- Merker (Memory): `MW0`, `MD4`, `M0.0`
- Inputs: `IW0`, `ID4`, `I0.0`
- Outputs: `QW0`, `QD4`, `Q0.0`

#### Data Type Support:
- `BOOL` - 1-bit values with bit offset extraction
- `INT` - 16-bit signed integer (big-endian)
- `DINT` - 32-bit signed integer (big-endian)
- `REAL` - 32-bit IEEE 754 float (big-endian)

#### Error Handling:
- Connection errors trigger automatic disconnect detection
- Network errors (OpError, EOF) properly handled
- Read errors return quality=1 (bad) with error details
- Timeout configuration for connect and read operations

#### Files Created:
- `internal/s7/client.go` - S7 protocol client library

### 2026-01-24 - S7 Driver MQTT Publishing (Iteration 7)

#### Completed User Stories:
- **US-014**: Implemented S7 driver data publishing to MQTT

#### Features Implemented:
- S7 client integration in `services/driver-s7/main.go`
- `connectS7()` - Creates S7 client from gateway connection_config and connects with retry
- `poll()` - Reads all tags using S7 client and publishes to MQTT
- `publishTagValue()` - Publishes tag value to MQTT with JSON payload
- `hasValueChanged()` / `updatePreviousValue()` - Report by Exception implementation
- `valuesEqual()` - Type-safe value comparison for BOOL, INT, DINT, REAL

#### MQTT Topic Structure:
- Topic format: `data/{org}/{site}/{area}/{gateway}/{alias}`
- All names are slugified (lowercase, spaces to hyphens)

#### MQTT Payload Format:
```json
{
  "v": <value>,
  "ts": <timestamp_ms>,
  "q": <quality>
}
```
- `v`: The tag value (bool, int16, int32, float32)
- `ts`: Unix timestamp in milliseconds
- `q`: Quality (0 = good, 1 = bad)

#### Report by Exception (RBE):
- Stores previous values in thread-safe map `previousValues`
- Only publishes when value has changed from previous read
- First read for any tag is always published
- Type-specific comparison for accurate change detection

#### Error Handling:
- Auto-reconnect to S7 PLC on connection loss
- Bad quality (q=1) published when read errors occur
- Graceful S7 disconnect on service shutdown
