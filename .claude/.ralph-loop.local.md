### Iteration 5: Database Schema Analysis
**Finding**: `historize` and `alarm_enabled` default to `FALSE` in schema.
- This is correct default behavior
- Users must explicitly enable these features
- With new logging, users can now see WHY features aren't working

## Root Causes Identified
1. **Tag Matching Failure**: Both engine-alarm and engine-historian used `LOWER()` but not `TRIM()`, causing failures when entity names had trailing/leading spaces
2. **Invisible Failures**: No logging meant failures were silent, making debugging impossible
3. **Unclear Trend Errors**: Generic error messages didn't help identify InfluxDB connection vs query syntax vs missing data issues
